Direction A: Column

Streams is a chat column. The IINA sidebar holds the stream’s identity, one toolbar of controls, and the chat filling the rest. With IINA’s own Edge-to-Edge Video turned off, the column sits beside the picture, like Twitch’s chat. Over-video chat stays as the lean-back mode for fullscreen.

1 · Watching live, chat beside the video

The plugin sidebar defaults to IINA’s leading (left) side. The user can move it to the right in IINA.

1b · The same, on a fresh install

Edge-to-Edge Video is on by default, so a new user first gets the column over the picture, as today.

2 · Sidebar states

Same skeleton in every state. Only the chat button and the message area change.

5 · Open Stream (⌃⌘O): quick open, keyboard first

A small standalone window, like Spotlight. Type to filter followed channels, or paste a URL. ↑↓ moves, Return opens. Offline channels expand into their recent broadcasts in place (#32).

6 · Quick actions (#52) without touching IINA’s controller

IINA 1.5.1’s plugin API has no call that adds a button to the on-screen controller (checked in the JS API sources, see README). Direction A puts nothing on the video. Quick actions are the LIVE badge in the column plus menu items with shortcuts, which also serve keyboard and VoiceOver users.
