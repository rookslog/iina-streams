Direction B: Stage

The video is the interface. Chat lives on the picture, either docked to the right edge as a full-height strip that the picture shrinks away from, or floating as a card. A small Streams cluster beside IINA’s controller carries LIVE, chat and placement. The IINA sidebar shrinks to a settings form you rarely open.

1 · Watching live, chat docked

Streams sets mpv’s video-margin-ratio-right to the strip’s share of the width, so the picture is drawn left of the strip. That works the same windowed and fullscreen, and needs no IINA setting.

2 · Floating

3 · The cluster beside IINA’s controller (#51, #52)

IINA 1.5.1 offers no API to add controller buttons, so the cluster is Streams’ own overlay, placed beside the controller. It should appear and hide with the controller, but the plugin API has no controller-visibility event: the cluster would follow mouse movement on its own. The controller’s position is also a user preference (floating and draggable, bottom, or top) that the plugin can’t read, so “beside the controller” can collide with it. Unverified

4 · Chat card states

Sign-in happens where chat would be: inside the card.

5 · The sidebar becomes a settings form

No messages, no status text. Opened from the cluster’s settings button or Plugins › Streams.

6 · Open Stream (⌃⌘O): browse window

A larger standalone window with thumbnails, closer to the Twitch home page. The search field still accepts a channel or URL. Offline channels open a channel page of recent broadcasts (#32).
